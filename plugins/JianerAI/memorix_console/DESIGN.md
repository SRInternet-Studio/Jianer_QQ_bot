# Memory Console Direction

The console uses the **Swiss** anchor for a memory operations workspace: the operator needs to scan live runtime state, retrieval evidence, and maintenance actions without visual noise. Its signature is a red folio index paired with a thin red position rule, so the current workspace remains easy to locate while moving between dense records.

The surface is pure white with neutral `#F7F7F8` bands, Helvetica Neue and system sans-serif fallbacks, Swiss Red `#E4002B`, and visible 1 px grid rules. Typography stays left-aligned; numerals carry section and record hierarchy. The content comes from the runtime API. Unavailable data stays empty and disconnected state is shown as such.
