# Memory Console Direction

The console uses the **Industrial** anchor because operators need to scan runtime health, retrieval evidence, and lifecycle work under pressure. The memorable move is a persistent signal rail: the left navigation and every operational status use the same green state color, while the rest of the surface stays black and quiet.

The surface is pitch black (`#000000`) with warm black panels (`#0B0C0A`), 1px structural rules (`#30332E`), and one semantic signal (`#00E676`). IBM Plex Mono, JetBrains Mono, and system monospace fallbacks are the only declared typefaces. Controls are flat rectangles with no rounded corners, blur, or decorative shadows. The content is populated from the runtime API; empty stores render an explicit empty state instead of invented records.
